# AstraCYD v0.2.2

Прошивка дополнительного дисплея Opel Astra H для ESP32-2432S028R с классическим ESP32, дисплеем ILI9341 и резистивным сенсором XPT2046.

## Проверка платы

Сверьте модель на обороте платы и тип дисплея перед установкой. Типичный исходный вариант имеет один micro-USB. У плат с micro-USB и USB-C встречаются другие настройки дисплея. USB-проверка определяет микроконтроллер и размер флеш-памяти. Она не определяет модель TFT или сенсора.

У проверенного устройства на COM14 обнаружены CH340, ESP32-D0WD-V3 v3.1 и флеш-память 4 МБ. Профиль сборки использует исходную распиновку ILI9341 и XPT2046. См. [описание ревизий CYD](https://github.com/witnessmenow/ESP32-Cheap-Yellow-Display/blob/main/cyd.md).

## Установка в Windows

Распакуйте архив в доступную для записи папку. Нужен Python 3.10–3.12 с pip. Если Python отсутствует в PATH, можно указать полный путь к python.exe в переменной окружения ASTRACYD_PYTHON. При первом запуске скрипт создаёт локальное окружение и загружает esptool 4.9.0. Подключите плату USB-кабелем для данных и закройте монитор последовательного порта.

```bat
install.cmd --probe --port COM14
install.cmd --backup-only --port COM14
install.cmd --install --port COM14
```

Подставьте актуальный COM-порт. Если обнаружен единственный поддерживаемый USB–UART, аргумент порта можно опустить. Режим установки самостоятельно сохраняет полный образ флеш-памяти в папку `backups`, проверяет размер, записывает SHA-256 и повторно сверяет MAC устройства. После успешного резервирования esptool записывает четыре образа по адресам PlatformIO и проверяет записанные данные. Режим `--backup-only` служит для отдельной копии.

Для восстановления на той же плате сравните SHA-256 образа с файлом `.sha256` (PowerShell: `Get-FileHash -Algorithm SHA256 <путь-к-образу>`). Укажите точный COM-порт и запишите полный образ с нулевого адреса. Параметры keep сохраняют исходные настройки заголовка.

```bat
.venv\Scripts\python.exe -m esptool --chip esp32 --port COM14 --baud 115200 write_flash --flash_mode keep --flash_freq keep --flash_size keep 0x0 "backups\ИМЯ_КОПИИ.bin"
```

[Документация esptool 4 по чтению и записи флеш-памяти](https://docs.espressif.com/projects/esptool/en/release-v4/esp32/esptool/basic-commands.html)

## Сборка

Распакуйте проект в папку с коротким путём, например C:\AstraCYD, чтобы избежать ограничения путей компилятора Windows. В корне проекта выполните `pio run -e cyd_2432s028r`. Arduino ESP32 и версии библиотек закреплены в `platformio.ini`. Профиль разделов `huge_app` выделяет 3 МБ приложению и рассчитан на установку через USB. Папка `firmware` содержит готовые образы выпуска. При локальной пересборке замените в ней `bootloader.bin`, `partitions.bin` и `firmware.bin` из `.pio/build/cyd_2432s028r`, а `boot_app0.bin` возьмите из `tools/partitions` пакета Arduino ESP32, использованного в сборке.

## Проверка после установки

1. Откройте последовательный монитор на 115200. Убедитесь, что видны четыре вкладки DRIVE, ENGINE, TRIP и SETUP. Проверьте, что каждое касание срабатывает один раз и что интерфейс отвечает во время подключения Bluetooth. Если координаты зеркальны, скорректируйте границы калибровки в `src/main.cpp` по сырым координатам из лога.
2. В стоящей машине подключите ELM327 и включите зажигание. Закройте приложение телефона, если оно заняло единственный SPP-сеанс. Прошивка ищет доступный для обнаружения адаптер Bluetooth Classic по имени `OBDII`. Если адаптер использует другое имя, укажите его в `ELM_NAME` в файле `src/main.cpp` и пересоберите прошивку. PIN 1234 или 0000 выбирается на вкладке SETUP и сохраняется в NVS.
3. Дождитесь `OBD OK` после первого действительного ответа ЭБУ и сравните обороты и температуру с диагностическим приложением. По OBD-II опрашиваются обороты, скорость, температура ОЖ, нагрузка и дроссель. ATRV показывает напряжение на адаптере. При потере соединения показания сбрасываются.
4. Для определения передачи используются близкие по времени RPM и скорость. Пять коэффициентов и пороги подсказок экспериментальны. Их нужно сверить для конкретной КПП. Выжатое или буксующее сцепление может исказить расчёт.
